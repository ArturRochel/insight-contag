Desenvolver um sistema de análise de dados e visualização de métricas operacionais a partir da planilha Excel utilizada pela CONTAG para registrar atendimentos de consultoria realizados às Unidades Gestoras do Estado.

---

# Tecnologias 

Para esse projeto vou utilizar tecnologias bases para a análise de dados e um frontend baseado na biblioteca Streamlit para diminuir o tempo de desenvolvimento e permitir a hospedagem gratuita.

| Camada       | Tecnologia                 | Função                      |
| ------------ | -------------------------- | --------------------------- |
| Linguagem    | Python 3.12                | Linguagem base do sistema   |
| Dados        | Google Sheets              | Fonte de dados acessível    |
| Tratamento   | Pandas                     | Leitura, limpeza e métricas |
| Gráficos     | Plotly                     | Gráficos interativos        |
| Frontend     | Streamlit                  | Interface web               |
| Documentação | MkDocs                     | Documentação do projeto     |
| Hospedagem   | Streamlit Community Cloude | URL pública gratuita        |

---
